登录令牌

登录 NapCat WebUI 用，扫码前先拿它

想省事就直接点「总览 → 访问入口 → NapCat」，那个磁贴是免密直达（链接里已经带上 token）。
要手动登录：打开 http://设备IP:6099， 再把上面按钮打印出来的 WebUI Token 粘进去。

写入反向 WebSocket

把 NapCat 的消息转发到 NoneBot2，并自动填好 token

会生成 onebot11_你的QQ号.json，内容指向 ws://127.0.0.1:8080/onebot/v11/ws，token 与 NoneBot2 的 ONEBOT_ACCESS_TOKEN 对齐。以后换端口只要重新点一次。

诊断与修复

连不上、插件没装、配置找不到时用

连不上 NoneBot2（控制台看不到已连接的 Bot）时先点「修复 NoneBot 连接」： 它会先等 GsCore 就绪，再重启 NoneBot2 重新连接。
若提示插件缺失，再点「修复桥接插件」重装 nonebot-plugin-genshinuid。

插件依赖检测与修复

扫插件里的 import 和 requirements.txt，看缺哪些 Python 包，一键装上

未扫描
点上面按钮开始。扫描会读 app/gscore/*/plugins/ 和 app/nonebot/plugins/ 里所有插件的 .py 与 requirements.txt， 列出每个插件已用、未装的包。
新装插件后第一次启动 GsCore，最常遇到 ModuleNotFoundError: No module named 'xxx'，大多是因为插件装了、它引用的 Python 包没装。 这页能扫出所有缺的，点「一键安装」就走国内源补齐。

两端 ws_token 对齐

一次性写入 GsCore 的 WS_TOKEN 和 NoneBot2 的 .env

同机部署时两边都留空也能连（不校验）。一旦要跨机、经隧道或对公网暴露，务必填一个。 改完会自动重启 GsCore 和 NoneBot2。

NapCat 侧的 token

这是另一个 token，别和上面混了

NapCat 有两处 token：
1. WebUI Token —— 登录 NapCat 网页后台用，点「NapCat 令牌」查看。
2. 反向 WS 的 access_token —— 与 NoneBot2 的 ONEBOT_ACCESS_TOKEN 必须一致， 点「写入反向 WS」会自动处理，不用手填。
